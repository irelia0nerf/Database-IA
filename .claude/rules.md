# Claude Rules — Mapeamento

Os standards de engenharia da FoundLab são a fonte canônica e vivem em
[`Core/Standards/`](../Core/Standards/). Este arquivo existe para resolver as referências
históricas no formato `@.claude/rules/...` que apareciam no `CLAUDE.md`.

| Referência antiga | Caminho canônico |
|-------------------|------------------|
| `@.claude/rules/code-style.md` | [`Core/Standards/code-style.md`](../Core/Standards/code-style.md) |
| `@.claude/rules/testing.md` | [`Core/Standards/testing.md`](../Core/Standards/testing.md) |
| `@.claude/rules/security.md` | [`Core/Standards/security.md`](../Core/Standards/security.md) |
| `@.claude/rules/git-workflow.md` | [`Core/Standards/git-workflow.md`](../Core/Standards/git-workflow.md) |

> Não duplique conteúdo aqui. Edite sempre o arquivo canônico em `Core/Standards/`.
